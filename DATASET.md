# Обучающие данные

Модель использует датасет unstonio/pixelgpt-24x24-20k по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Сам набор данных не входит в репозиторий: scripts/train.py загружает опубликованный обучающий раздел при необходимости.

Паттерны строятся из исходных 24×24 спрайтов через несколько мягких орнаментальных преобразований. Сценарий балансирует пять направлений — fauna, botanical, terrain, geometry и textile — и экспортирует для каждого отдельный диапазон скрытых векторов. В браузере эти диапазоны дополнительно проходят через симметрию, ограничение пустого поля, дизеринг и гармонизацию палитры, поэтому исходные объекты превращаются в повторяемые мотивы, а не воспроизводятся буквально.
