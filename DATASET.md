# Обучающие данные

Модель использует датасет unstonio/pixelgpt-24x24-20k по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Сам набор данных не входит в репозиторий: scripts/train.py загружает опубликованный обучающий раздел при необходимости.

Паттерны строятся из исходных 24×24 спрайтов через несколько мягких орнаментальных преобразований. Сценарий балансирует пять направлений — fauna, botanical, terrain, geometry и textile — смешивает небольшие зеркальные сектора и экспортирует для каждого отдельный диапазон скрытых векторов. Для каждого вектора рассчитывается простой показатель композиционного качества, поэтому браузер отбрасывает самые пустые и плоские варианты. В браузере оставшиеся диапазоны дополнительно проходят через симметрию, секторные микро-мотивы, ограничение пустого поля, дизеринг и гармонизацию палитры.
